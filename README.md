# MathType 公式编号 · 章号自动跟随标题

一个 Word 全局模板（`.dotm`），让 MathType 的公式编号 `(3.1)`、`(4.2)` 里的**章号**自动等于所在章标题的编号，保存时自动同步。

不改 MathType 的编号格式、不改它的交叉引用机制，装一次对所有文档生效。

---

## 它解决什么问题

MathType 的编号是这样一个 Word 域：

```
{ MACROBUTTON MTPlaceRef
    { SEQ MTEqn \h }
    ( { SEQ MTChap \c } . { SEQ MTEqn \c } ) }
```

公式序号（`MTEqn`）由 MathType 自己维护，**章号（`MTChap`）却是一个独立计数器**，只由 MathType 的「章节分隔符」驱动。于是常见的结果是：

- 增删章节、调整顺序后，公式编号不跟着变；
- 更常见的是彻底错位，比如公式在第 4 章却显示 `(2.1)`，或者全变成 `(0.1)`。

本工具在每个「一级标题」后面放一个**不可见**的锚点：

```
{ SEQ MTChap \r N \h }
```

`\c` 于是永远显示当前章的编号。MathType 的编号域一个字节都没动。

---

## 功能

| 功能 | 说明 |
|---|---|
| **章号自动跟随** | 增、删、移动章节后，保存一次即全部重排 |
| **完全保留 MathType 设置** | 编号样式 `1,2,3` / `I,II,III` / `a,b,c`、括号、分隔符、附件，全部仍由 MathType「格式化公式编号」决定 |
| **交叉引用不受影响** | MathType 的「插入公式引用」、更新编号、书签跳转照常工作 |
| **自动 + 手动** | 保存 / 打印 / 另存为前自动同步；也可以随时点「立即同步编号」 |
| **可一键关闭** | 「关闭自动同步」后，保存和打印完全跳过，零耗时 |
| **全局生效** | 装在 Word 的 STARTUP 目录，所有文档自动可用，不用每篇重新配置 |
| **快** | 结构有变化约 0.5 秒，结构没变化约 0.1 秒（319 段实测） |

## 安装（换电脑也是这三步）

1. 正常安装 MathType；
2. **关闭所有 Word 窗口**；
3. 右键 `install.ps1` → **使用 PowerShell 运行**；或者：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```

脚本只做两件事：

- 把 `MathTypeChapSync.dotm` 复制到 `%APPDATA%\Microsoft\Word\STARTUP\`；
- 把该目录登记为 Word 的「受信任位置」，避免宏被安全策略拦住。

不需要管理员权限，不动 MathType，不改系统目录。

装完打开 Word，在 **引用** 选项卡最右边会出现 **「公式编号」** 组。

## 使用

### 三个按钮

位置：**引用 → 公式编号**

| 按钮 | 作用 |
|---|---|
| **立即同步编号** | 马上同步一次；结果显示在左下角状态栏 |
| **开启自动同步** | 保存 / 打印 / 另存为前自动同步（默认状态） |
| **关闭自动同步** | 保存 / 打印时不再同步，适合文档很大的时候临时提速 |

### 日常用法

1. 正常写论文，正常用 MathType 插公式、插编号、插引用；
2. 按 `Ctrl+S` —— 编号会自动修正为当前章号；
3. 增删章节后同样只需保存一次，后续所有公式的章号自动重排。

同步结果只在状态栏显示，例如：

```
公式编号已同步：4 章（有更新） 20:31:07
```

不弹窗、不打断。

### 怎么确认生效

- 公式编号应形如 `(3.1)`、`(4.2)`，与所在章一致；
- `Alt+F9` 显示域代码，每个章标题后能看到 `{ SEQ MTChap \r 3 \h }`；
- 在第 4 章插入一个新公式，编号应直接是 `(4.x)`。

## 已知限制

- **只认“大纲级别 1 + 自动编号”的标题**。手打的“第4章”、没有多级列表编号的标题不会被当作章（摘要、致谢这类不编号的标题因此会被自动跳过）。
- **第一章之前的公式**（如果存在）显示为 `(0.x)`，因为那里还没有章号。
- **附录**如果也用一级标题并单独编号（A、B…），会按顺序被算成 5、6…；需要单独规则要改代码。
- **不要再用 MathType 的「插入章节分隔符」命令**：本工具自己管理锚点，两套混用会互相覆盖。
- 模板里的宏若被安全策略禁用，功能会失效——把 STARTUP 目录加入受信任位置即可（安装脚本已做）。

## 卸载

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
```

卸载后，已写入文档的 `SEQ MTChap \r N \h` 锚点仍留在文档里（不可见、无害），编号保持最后一次同步的结果；需要清除可 `Alt+F9` 后手工删除。

## 工作原理（给想改代码的人）

1. 扫描文档，找出「大纲级别 1 且有自动编号」的段落，取它们的编号；
2. 在每章标题后面的段落起点插入一个隐藏域 `{ SEQ MTChap \r N \h }`；
3. 只刷新 `SEQ MTChap` 的 `\c` 显示域；
4. 下次同步前先比较「应有的锚点序列」与「文档里实际的锚点序列」——一致就直接返回，一个字节都不改（这就是 0.1 秒快路径的来源）。

MathType 的 `MACROBUTTON MTPlaceRef` 外层域从不被更新，避免破坏它的编号与引用。

## 常见问题

**问：编号变成 `(0.1)` 了？**
说明章号计数器没有锚点。点「立即同步编号」，或保存一次。

**问：点按钮报「错误的参数号或无效的属性赋值」？**
这是 Word 对功能区 `getPressed` 状态回调的兼容问题，本项目已改为纯 `onAction` 按钮规避。如果你用的是旧版本，请更新到当前模板。

**问：会影响别人打开我的文档吗？**
不会。锚点是标准 Word 域，任何 Word 都能正常显示；只是对方没装本工具时，编号不会自动重排。

**问：能不能不用 MathType 的编号、改用 Word 域？**
可以，但那样会失去 MathType 的引用跳转，不属于本项目的目标。
